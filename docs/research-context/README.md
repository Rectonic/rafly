## One-Paragraph Project Brief

LastBite is a mobile-first surplus-food marketplace. Buyers discover nearby discounted meals, baked goods, groceries, vegan items, and surprise bags; reserve an offer; recover pickup codes from reservation history; receive local pickup reminders; and use English or Russian UI. Sellers register as restaurants or shops, complete a setup checklist, create meal-package offers, track shop inventory through manual/barcode/OCR intake, and manage pickup orders. The current app is an Expo/React Native iOS product with Supabase as the intended shared backend, local-first fallback for some buyer flows, and a substantial simulator-tested MVP. It is simulator-preview ready but not production-ready until real Supabase migrations/E2E, physical iPhone camera/OCR/notification QA, signing/TestFlight, and production RLS/security checks are complete.

## Important Context Compression Notes

- Early design docs describe a buyer-only MVP. The current app has evolved beyond that into buyer plus seller mobile workflows.
- Older architecture notes recommended SwiftUI for a future production iOS app. The implemented MVP uses Expo/React Native for speed and shared TypeScript patterns.
- Real backend validation has recently advanced: the Supabase auth smoke command now reaches the schema and reports `auth_ok_profile_missing` for the provided seller, meaning credentials work and the seller needs onboarding/profile creation.
- Physical iPhone install has succeeded before, but remote launch can be blocked when iOS reports the device as locked. Manual launch from the phone may still work after install.
