# Сценарий записи экрана Rafly

## Параметры записи

- Ожидаемая длина одного дубля: 2 минуты 50 секунд.
- Формат: 1920 x 1080 или 1440 x 900, 30 кадров в секунду.
- Масштаб браузера: 90 процентов для окна 1440 x 900, 100 процентов для Full HD.
- Курсор: видимый, обычного размера, без эффекта кругов.
- Звук интерфейса: выключен. Дикторский текст записывается отдельно.
- Сеть продукту не нужна. Локальный сервер используется только для стабильного адреса в браузере.

## Подготовка до нажатия записи

1. Из корня репозитория запустить локальный сервер:

```bash
python3 -m http.server 8080
```

2. Открыть точный маршрут:

```text
http://localhost:8080/docs/pta/demo/index.html#step-1
```

3. Нажать `Сбросить демо`, если страница уже была открыта.
4. Убедиться, что сверху видна плашка `Демонстрация на вымышленных данных`.
5. Закрыть панель закладок, загрузки, менеджер паролей и уведомления системы.
6. Поставить курсор на свободное место справа от заголовка первого шага.
7. Не включать веб-камеру и не показывать адресную строку после первых двух секунд.

## Данные образца

### Анкета

- Название: `Магазин «Саховат»`
- Роль: `Владелец`
- Источник каталога: `CSV из старой кассы`
- Состояние POS: `Есть, остатки не ведутся`

### CSV

```csv
название,штрихкод,количество,цена
Сыр голланд 200г,4780012345601,6,24000
Кефир 1% 1л,4780012345602,4,12000
Йогурт клубника 180г,4780012345603,7,8000
Сыр голл. 200 г,,6,24000
```

### Пересчёт

- Фактическое количество: `6`

### Оффер

- Название: `Сыр «Голландский» 200 г`
- Количество: `3`
- Категория: `Продукты`
- Цена предложения: `12000`
- Подтверждённая базовая цена: `24000`
- Начало самовывоза: `18:00`
- Конец самовывоза: `21:00`

### Выдача и исключение

- Код самовывоза: `7K2M9Q`
- Фактическое количество при расхождении: `0`
- Причина расхождения: `Менеджер проверил подписанный резерв. Единица для этой брони не найдена.`
- Комментарий к решению: `Пересчитан подписанный физический резерв. Две единицы найдены, одна единица из невыданной брони освобождена после ручной проверки.`

## Контроль одного дубля

- На каждом шаге верхняя плашка образца остаётся видимой.
- Не перескакивать через шаги боковой навигацией.
- На неоднозначной строке сначала показать отказ, затем выбор человека.
- На пересчёте сначала отправить предложение, затем отдельно нажать `Одобрить`.
- На публикации сначала нажать `Проверить перед публикацией`, затем отдельно `Одобрить и опубликовать`.
- На камере удержать исследовательскую маркировку до любого действия.
- На исключении сначала показать выключенную кнопку, затем ввести комментарий.
- После решения оффер должен остаться на паузе, а безопасный потолок должен стать 4.
- Если сделана ошибочная кнопка или изменено значение образца, остановить запись, нажать `Сбросить демо` и начать новый дубль с точного маршрута.
