# Логотип Rafly

## Какой файл использовать

- `rafly-mark.svg` для аватара, интерфейса, небольшого знака и цветной печати.
- `rafly-wordmark.svg` для латинского названия без знака.
- `rafly-wordmark-ru.svg` для кириллического названия в русском материале.
- `rafly-lockup-horizontal.svg` как основную компоновку для двери, сайта, документов и презентационных материалов.
- `rafly-lockup-vertical.svg` для квадратной или узкой площади.
- `rafly-mark-mono-dark.svg` для печати одной тёмной краской на светлом материале, термоэтикетки и штампа.
- `rafly-mark-mono-light.svg` для одноцветного применения на фоне Ink или другом достаточно тёмном фоне.
- `rafly-favicon.svg` для вкладки браузера. Мастер рассчитан на 32 px и остаётся читаемым при 16 px.
- `rafly-appicon.svg` как мастер иконки приложения 1024 на 1024 px. Не добавляйте к нему внешние поля или скругление.

## Форматы экспорта

Для экрана используйте исходный SVG. Для систем, которые не принимают SVG, экспортируйте PNG в точном целевом размере с прозрачностью. App icon экспортируйте из мастер-файла в PNG 1024 на 1024 px, затем создайте платформенные размеры без изменения композиции.

Для печати передавайте SVG или экспортированный PDF. Перед отправкой в типографию переведите текст вордмарка в кривые в профессиональном редакторе и проверьте размер. Для термопечати, штампа и печати одной краской используйте только монохромные версии. JPEG для логотипа не использовать.

## Охранное поле

Обозначим через `M` полную сторону квадратного viewBox знака. Со всех сторон знака и любой компоновки оставляйте свободное поле не меньше `0,25M`. В горизонтальной и вертикальной компоновках `M` определяется стороной знака, а не высотой букв.

Внутри `rafly-favicon.svg` и `rafly-appicon.svg` безопасное поле уже заложено. Не добавляйте ещё `0,25M` внутрь этих файлов.

## Минимальные размеры

| Версия | Печать | Экран |
| --- | ---: | ---: |
| Знак | 10 мм | 16 px |
| Горизонтальная компоновка | 32 мм | 120 px |
| Вертикальная компоновка | 20 мм | 72 px |
| Вордмарк | 24 мм | 96 px |
| Одноцветный штамп | 10 мм | не применяется |
| Фавикон | не применяется | 16 px |

Не растягивайте, не поворачивайте и не перекрашивайте части знака. Не добавляйте градиенты, контуры, тени, бейджи или подписи внутрь охранного поля.
