# AGENT: ДИЗАЙН — LastBite

> Ты — senior product designer. Твоя задача — создать полный UI/UX дизайн для приложения LastBite (веб + мобильное). Ниже — исчерпывающее ТЗ. Работай последовательно: сначала design system, потом user flows, потом экраны.

---

## 1. О ПРОДУКТЕ

**LastBite** — маркетплейс, где рестораны, кафе, пекарни и магазины продают остатки еды и товаров со скидкой 40-70%. Пользователь видит предложения рядом с собой, бронирует и забирает. Бизнес вместо выбрасывания — возвращает часть выручки.

**Две стороны приложения:**
- **Покупатель (Buyer App)** — основное приложение, веб + мобильное
- **Продавец (Seller Dashboard)** — панель управления для бизнеса, приоритетно веб

**Тон бренда:** дружелюбный, экологичный, чуть игривый. Не «спасаем планету» пафосно, а «выгодно и вкусно, а планете тоже хорошо». Молодая аудитория 18-35.

### 2.5 Компоненты (базовый набор)

Нужно спроектировать:

**Кнопки:**
- Primary (зелёный, белый текст)
- Secondary (обводка зелёная, зелёный текст)
- Ghost (только текст)
- Danger (красный, для отмены)
- Состояния: default, hover, pressed, disabled, loading

**Карточка предложения (главный компонент):**
- Фото (соотношение 16:9 или 4:3)
- Badge скидки (например, «-60%», оранжевый)
- Название заведения
- Описание/позиции
- Старая цена (зачёркнутая) → Новая цена (крупная, зелёная)
- Таймер обратного отсчёта (сколько осталось)
- Расстояние от пользователя
- Рейтинг (звёзды или числовой)
- Тип: badge «Surprise bag» или «Выбор позиций»
- Кнопка «Забронировать»

**Карточка заведения (для страницы заведения):**
- Обложка
- Лого/аватар
- Название, категория, адрес
- Рейтинг, количество отзывов
- Время работы
- Список текущих предложений

**Таймер:**
- Формат: `ЧЧ:ММ:СС` или `ММ:СС` если < 1 часа
- Цветовая кодировка: зелёный > 30 мин, оранжевый 10-30 мин, красный < 10 мин
- Анимация пульсации при < 5 мин

**Навигация (мобильное):**
- Bottom tab bar: Главная, Карта, Избранное, Заказы, Профиль
- 5 иконок, активная — Primary цвет, неактивная — серая

**Навигация (веб):**
- Top navbar: логотип слева, поиск по центру, геолокация + профиль справа
- Sidebar для категорий (desktop)

## 3. USER FLOWS — ПОКУПАТЕЛЬ

### Flow 1: Онбординг
```
Splash → Запрос геолокации → Главный экран (без регистрации)
                            ↓ (при бронировании)
                       Регистрация (телефон + SMS или OAuth)
```
**Важно:** пользователь видит предложения БЕЗ регистрации. Регистрация — только при первом бронировании. Минимальный friction.

### Flow 2: Поиск и бронирование
```
Главный экран (лента) → Фильтры (категория, расстояние, тип)
       ↓                         ↓
Карточка предложения → Страница предложения (детали)
                              ↓
                    Выбор количества → Оплата → Подтверждение
                                                    ↓
                                           QR-код для получения
```

### Flow 3: Карта
```
Карта с маркерами → Тап на маркер → Preview карточка → Страница предложения → Бронирование
```

### Flow 4: Получение заказа
```
Мои заказы → Активный заказ → QR-код + адрес + навигация
                                    ↓
                           Показать продавцу → Получено → Оценить
```

### Flow 5: Surprise Bag
```
Карточка с badge «Surprise Bag» → Описание (категория еды, вес/объём, НЕ конкретные позиции)
       ↓
Забронировать → Оплата → QR → Получение → Распаковка (фото что получил) → Оценить
```

## 4. ЭКРАНЫ — ПОКУПАТЕЛЬ (мобильное)

### 4.1 Splash / Онбординг
- Логотип LastBite по центру
- 2-3 onboarding слайда (swipe): «Выгодно ешь», «Спасай еду», «Рядом с тобой»
- CTA: «Начать» → запрос геолокации

### 4.2 Главный экран (Home)
- **Верх:** Приветствие + текущая геолокация (тап для изменения)
- **Поисковая строка** (placeholder: «Что ищешь?»)
- **Горизонтальная лента категорий:** иконки + подписи (Рестораны, Пекарни, Магазины, Цветы, Surprise Bags, Все)
- **Секция «Заканчивается скоро»:** горизонтальный scroll карточек с таймером < 30 мин (urgency)
- **Секция «Рядом с тобой»:** вертикальная лента карточек, сортировка по расстоянию
- **Секция «Лучшие предложения»:** карточки с максимальной скидкой
- Pull-to-refresh

### 4.3 Карта
- Полноэкранная карта (Google Maps / Mapbox)
- Кластеризация маркеров при zoom out
- Маркеры: кастомные иконки по категории (вилка для ресторана, хлеб для пекарни и т.д.)
- При тапе на маркер — bottom sheet с preview карточкой
- Кнопка «Моя локация» (GPS)
- Фильтры сверху (категория, скидка, тип)

### 4.4 Страница предложения (Detail)
- Фото-карусель (swipe)
- Badge скидки
- Название заведения (тап → страница заведения)
- Описание предложения
- Для «Выбор позиций»: список с чекбоксами, цена каждой
- Для «Surprise Bag»: описание категории, примерный вес, НЕ конкретные позиции
- Таймер: «Забрать до ЧЧ:ММ»
- Старая цена → Новая цена
- Кнопка «+/-» для количества
- Sticky bottom bar: общая сумма + «Забронировать»
- Секция «Отзывы» (последние 3 + «Показать все»)

### 4.5 Оплата
- Сводка заказа
- Выбор способа оплаты (карта, Apple Pay, Google Pay)
- Добавление карты
- Промокод
- Кнопка «Оплатить»

### 4.6 Подтверждение бронирования
- Анимация успеха (lottie чекмарк)
- QR-код (крупный, по центру)
- Адрес заведения + кнопка «Маршрут» (открывает навигатор)
- Время получения: «Забрать с ЧЧ:ММ до ЧЧ:ММ»
- Таймер обратного отсчёта
- Кнопка «Мои заказы»

### 4.7 Мои заказы
- Табы: Активные | Завершённые
- Активные: карточка с QR, адресом, таймером, кнопка «Показать QR»
- Завершённые: карточка с датой, суммой, оценкой, фото (если surprise bag)

### 4.8 Страница заведения
- Обложка + лого
- Название, категория, рейтинг, кол-во отзывов
- Адрес (тап → карта)
- Часы работы
- Текущие предложения (карточки)
- Отзывы

### 4.9 Избранное
- Список избранных заведений (карточки)
- Пустое состояние: иллюстрация + «Добавь заведения, чтобы не пропустить выгодные предложения»
- Уведомления: toggle «Уведомлять о новых предложениях»

### 4.10 Профиль
- Аватар + имя
- Статистика: «Ты сэкономил(а) Х₽» и «Спас(ла) Y кг еды» (геймификация)
- Настройки уведомлений
- Способы оплаты
- История заказов
- Помощь / FAQ
- Выход

### 4.11 Оценка после получения
- Рейтинг (1-5 звёзд)
- Quick tags: «Свежее», «Щедрая порция», «Как на фото», «Мало», «Не свежее»
- Фото (опционально, особенно для surprise bag — «покажи что получил»)
- Текстовый отзыв (опционально)

## 6. ЭКРАНЫ — ПРОДАВЕЦ (Seller Dashboard)

### 6.1 Онбординг продавца
```
Регистрация (телефон/email) → Информация о заведении (название, адрес, категория, фото)
       → Подтверждение → Дашборд
```
**Максимально простой онбординг: 2-3 шага, заполнение за 2 минуты.**

### 6.2 Дашборд (главная продавца)
- Приветствие + название заведения
- **Карточки-метрики верхом:**
  - Продано сегодня (количество + сумма)
  - Активных предложений
  - Средний рейтинг
  - Сэкономлено от выбрасывания (кг)
- **Быстрое действие: кнопка «+ Добавить предложение»** (большая, заметная)
- **Активные предложения:** список с таймерами и количеством бронирований
- **Последние заказы:** список ожидающих получения

### 6.3 Добавление предложения
- **Шаг 1:** Фото (камера или галерея) — можно пропустить
- **Шаг 2:** Тип — «Surprise Bag» или «Конкретные позиции»
  - Surprise Bag: категория (выпечка/готовая еда/смешанное), описание, примерный вес
  - Конкретные позиции: список позиций (название + кол-во + оригинальная цена)
- **Шаг 3:** Цена со скидкой + количество доступных порций
- **Шаг 4:** Время получения (с ЧЧ:ММ до ЧЧ:ММ)
- **Публикация** — одна кнопка

**Весь процесс — максимум 30-60 секунд. Никаких лишних полей.**

### 6.4 Управление предложениями
- Список активных предложений
- Для каждого: редактировать количество, продлить/сократить время, снять с публикации
- История прошлых предложений

### 6.5 Заказы
- Список забронированных заказов
- Статус: ожидает получения / получен / не забран (no-show)
- При получении: продавец сканирует QR покупателя → подтверждение
- Кнопка «Отметить как полученный» (ручная, если QR не работает)

### 6.6 Аналитика
- Графики: выручка от остатков по дням/неделям
- Сколько кг еды спасено
- Популярные позиции
- Средний рейтинг и отзывы
- Время пиковых заказов (когда добавлять предложения)

### 6.7 Профиль заведения
- Редактирование информации: название, адрес, фото, категория
- Часы работы
- Банковские реквизиты для выплат

### 6.8 Push-напоминание продавцу
- Автоматическое уведомление в привычное время: «Обычно вы добавляете предложения в 20:00 — не забудьте!»
- Настраиваемое в профиле

## 7. СОСТОЯНИЯ И EDGE CASES

Для каждого экрана нужны состояния:
- **Empty state:** нет предложений рядом, нет заказов, нет избранного — иллюстрация + текст + CTA
- **Loading state:** skeleton-экраны (не спиннеры)
- **Error state:** нет сети, ошибка сервера — иллюстрация + «Повторить»
- **Expired:** предложение истекло пока пользователь на странице — overlay «Время вышло» + «Смотреть другие»
- **Sold out:** все порции забронированы — badge «Разобрали» + «Уведомить когда снова будет»
- **No-show:** пользователь не забрал заказ — уведомление + запись в историю

## 8. АНИМАЦИИ И МИКРО-ИНТЕРАКЦИИ

- Таймер: плавное обновление каждую секунду, пульсация при < 5 мин
- Бронирование: confetti/lottie анимация успеха
- Pull-to-refresh: кастомная анимация (иконка еды)
- Скелетон-загрузка: shimmer эффект
- Карточка: лёгкая тень при scroll, press-эффект
- Swipe на карточке в «Мои заказы» — показать QR
- Маркеры на карте: bounce при появлении
- Статистика в профиле: анимированные counters

## 9. ИКОНОГРАФИЯ И ИЛЛЮСТРАЦИИ

**Иконки:**
- Стиль: линейные (outline), 24x24px, stroke 1.5px
- Набор: Lucide или Phosphor Icons
- Категории: уникальная иконка для каждой (ресторан = вилка+нож, пекарня = круассан, магазин = корзина, цветы = цветок, surprise = подарок)

**Иллюстрации:**
- Стиль: плоские, минималистичные, в цветовой палитре приложения
- Для пустых состояний, онбординга, страницы успеха
- Нужны: пустой пакет (нет предложений), довольный человек с пакетом (успех), карта с маркерами (онбординг), планета с сердцем (экология)

**Логотип:**
- Сочетание иконки (надкусанный/спасённый элемент еды) + текст «LastBite»
- Должен работать на белом и тёмном фоне
- Варианты: полный, иконка-only, горизонтальный
